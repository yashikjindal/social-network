# Social Network (DAA Project)

This is a web-based **Social Network** application built using Python, Flask, and HTML/CSS/JS.

## 🚀 How to Run this Project Locally (Chalane ka Tarika)

Follow these steps to run the project on your computer:

### 1. Clone the Repository
Sabse pehle is project ko apne computer me download karne ke liye terminal me ye command chalayein:
```bash
git clone https://github.com
```
*(Ya fir aap upar diye gaye hare **Code** button par click karke **Download ZIP** bhi kar sakte hain aur use extract kar sakte hain).*

### 2. Navigate to the Folder
Terminal me project folder ke andar jayein:
```bash
cd social-network
```

### 3. Install Dependencies
Project ke liye zaroori libraries (jaise Flask) ko install karne ke liye ye command run karein:
```bash
pip install -r requirements.txt
```

### 4. Run the Application
Ab main application ko start karne ke liye ye command chalayein:
```bash
python app.py
```

### 5. Open in Browser
App shuru hone ke baad apne browser me ye link kholein:
```text
http://127.0.1:5000
```
